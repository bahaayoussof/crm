# Definition of Done

A feature is not complete just because the happy-path UI renders.

## Required

- matches documented scope
- TypeScript has no relevant errors
- request/input validation exists
- backend authorization exists where required
- loading state handled
- empty state handled
- error state handled
- success state handled
- responsive behavior checked
- no secrets committed
- no unrelated refactor
- relevant tests added or updated when valuable
- relevant documentation updated

## Before Hand-Off

AI reports:

```text
Feature:
Branch:
Files changed:
Behavior implemented:
Tests/checks run:
Known limitations:
Suggested commit message:
```

## Git Rule

The AI stops before commit, merge, or push.
